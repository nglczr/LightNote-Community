# LightNote — Comunidade

Hub público do **LightNote**, o editor leve de código e notas para Windows. Este
repositório é o ponto de encontro de quem usa o aplicativo: aqui ficam as
**discussões**, os **relatos de problemas** e os **downloads** da edição gratuita.

> O código-fonte do aplicativo é mantido em um repositório privado. Este espaço é
> dedicado à comunidade e à distribuição.

## 💬 Participe

- **Sugestões, dúvidas e ideias:** use as [Discussions](https://github.com/nglczr/LightNote-Community/discussions).
- **Encontrou um bug?** Abra uma [issue](https://github.com/nglczr/LightNote-Community/issues/new/choose).

## ⬇️ Download

- **LightNote (grátis):** baixe a versão mais recente em [Releases](https://github.com/nglczr/LightNote-Community/releases/latest) — para uso **pessoal e não comercial**.
- **LightNote Core (Microsoft Store):** para **uso comercial** e para apoiar o desenvolvimento, com atualizações automáticas. (Link da Store em breve.)

As duas edições têm **exatamente os mesmos recursos**.

## ☕ Apoie o projeto

O LightNote é mantido por uma só pessoa. Se ele te ajuda, considere apoiar no
[Ko-fi](https://ko-fi.com/lightnote) — ou adquira o **LightNote Core** na Store.
